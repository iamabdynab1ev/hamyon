# Hamyon

Учёт доходов и расходов для семьи и небольшого бизнеса.

Приложение на Flutter работает на телефоне и в браузере. Свой сервер на Go даёт
семье общие данные между устройствами: у каждого свой вход, владелец видит
сводку по всем.

## Возможности

- доходы, расходы, счета в разных валютах
- бюджеты с периодами и лимитами по категориям
- цели накопления, долги и рассрочки
- подписки и повторяющиеся платежи
- разделение счёта между людьми
- импорт и экспорт CSV
- интерфейс на узбекском, таджикском, русском и ещё 46 языках

## Общие данные семьи

Устройства обмениваются файлами изменений через свой сервер. Каждое выкладывает
свои правки, остальные их забирают и сливают у себя — работает и без связи,
данные догоняются при следующем подключении.

| Роль | Права |
|---|---|
| владелец | видит операции всех, сводку по семье, управляет участниками |
| участник | вносит свои операции, видит общий бюджет |

Родные подключаются по короткому коду приглашения, который выдаёт сервер
владельцу.

## Структура

```
budget/    приложение на Flutter
  lib/       код: экраны, база данных, синхронизация
  assets/    переводы, иконки, шрифты
server/    сервер на Go: аккаунты, роли, обмен файлами синхронизации
  internal/  ядро
  migrations/схема базы
```

## Запуск

**Приложение** — нужен Flutter 3.19.6:

```bash
cd budget
flutter pub get
flutter run -d chrome
```

**Сервер** — нужен Docker:

```bash
cd server
cp .env.example .env      # заполнить пароль базы и ключ подписи токенов
docker compose up -d --build
```

Подробности по серверу и описание API — в [server/README.md](server/README.md).

## Разработка
